# AGENTS.md

## Overview

This repository is a **Homebrew formula collection** (`beck`) containing Ruby-based formula definitions for various development tools. It is not a traditional application codebase but rather a set of packaging recipes for installing and managing tools via Homebrew.

## Repository Structure

```
beck/
├── Formula/           # Ruby formula definitions (one per tool)
│   ├── beck.rb       # CLI tool for managing beck workspaces
│   ├── upsun.rb       # Upsun deployment automation CLI
│   ├── infra.rb       # Infrastructure management tool
│   ├── beckkit.rb    # Kraftkit (unikernel build tool)
│   ├── beckcluster.rb # Beck cluster management tool
│   ├── beckcloud-cli.rb # AWS Cloud CLI wrapper
│   ├── brew-beck.rb  # Main beck project formula (generated)
│   └── update-brew.sh # Script to update Homebrew itself
├── Scoops/            # Scoop configurations (JSON)
│   ├── beck.json
│   ├── upsun.json
│   ├── infra.json
│   ├── beckkit.json
│   ├── beckcluster.json
│   ├── beckcloud-cli.json
│   └── brew-beck.json
├── Cask/              # macOS app installations (if needed)
└── README.md          # Project overview
```

## Project Type

This is a **Homebrew formula repository**. The "source code" consists of Ruby classes that define how to install, configure, and test each tool. These are packaging recipes, not application logic.

## Key Files

### Formula Files (`Formula/`)
Each formula is a Ruby class inheriting from `Formula` that defines:
- **Description** – human-readable tool description
- **Homepage** – official project URL
- **Version** – current release version
- **Dependencies** – `depends_on` declarations for required packages
- **Installation logic** – `on_macos` and `on_linux` conditionals for architecture-specific installs
- **Test block** – verification that the tool installs correctly

### Scoop Files (`Scoops/`)
Scoop configurations (JSON) mapping Homebrew formulas to Scoop packages for easy installation via Scoop.

### README.md
High-level project overview and usage instructions.

## Architecture & Patterns

### Formula Pattern
All formulas follow the standard Homebrew pattern:

```ruby
class ToolName < Formula
  desc "Tool description"
  homepage "https://example.com"
  version "1.0.0"
  
  on_macos do
    # macOS-specific installation
  end
  on_linux do
    # Linux-specific installation
  end
  
  test do
    system "#{bin}/#{tool_name}" "--version"
  end
end
```

### Conditional Installation
Formulas use `Hardware::CPU.arm?`, `Hardware::CPU.intel?`, and architecture checks to provide optimal builds for different hardware targets.

### Testing
Each formula includes a `test` block that runs `system "#{bin}/<tool>" "--version"` to verify successful installation.

## Commands for Agents

Agents working in this repository should know:

### Core Homebrew Commands
- `brew install <formula>` – Install a tool (e.g., `brew install beck`)
- `brew upgrade <formula>` – Upgrade a tool
- `brew list` – List installed formulas
- `brew search <term>` – Search for formulas
- `brew doctor` – Diagnose system health
- `brew cleanup` – Remove cached formula archives
- `brew tap <user>/<repo>` – Add this tap to Homebrew

### Tap Installation
To install tools from this tap:
```bash
brew tap beck/tap
brew install beck/tap/<formula>
```

### Formula-Specific Usage
- **beck** – `brew install beck` (CLI for managing beck workspaces)
- **upsun** – `brew install upsun` (deployment automation)
- **infra** – `brew install infra` (infrastructure management)
- **beckkit** (kraftkit) – `brew install beckkit` (unikernel build tool)
- **beckcluster**, **beckcloud-cli** – Similar installation patterns
- **brew-beck** – Main project formula
- **update-brew.sh** – Update Homebrew itself (run outside Homebrew)

## Naming Conventions

- **Formula names**: lowercase with hyphens (e.g., `beck`, `upsun`, `infra`)
- **Class names**: PascalCase matching the formula name (e.g., `Beck`, `Upsun`)
- **Descriptions**: Triple-quoted strings with clear, concise tool purpose
- **Versions**: Semantic versioning (e.g., `"0.3.0"`, `"5.0.21"`)

## Gotchas & Non-Obvious Patterns

1. **Generated Files** – Several formula files (e.g., `brew-beck.rb`) are generated by GoReleaser and should not be edited directly.
2. **Architecture Detection** – Formulas use `Hardware::CPU.arm?` and `Hardware::CPU.intel?` to select the correct binary tarball variant.
3. **Completion Generation** – Many formulas call `generate_completions_from_executable` to create shell completions for bash/zsh/fish.
4. **Scoop Mapping** – The `Scoops/` directory maps Homebrew formulas to Scoop packages; agents may need to consult this for Scoop-based installation.
5. **Test Reliance** – The `test` block relies on the tool producing a `--version` output; this may vary across implementations.
6. **Class Name vs Binary Name** – Some formulas install a binary with a different name than the class (e.g., `Beck` class installs `brev` binary).

## Getting Started

1. Install Homebrew if not already present
2. Navigate to the repository: `cd beck`
3. Add the tap: `brew tap beck/tap`
4. Install a tool: `brew install beck`
5. Verify installation: `brew list beck`
